Video codec optimizations and validation
=======================================

Implementation studies and reproducible validation materials for video codecs.

The AArch64 SIMD validation toolkit and historical benchmark are available in
the `codec-simd-validation <codec-simd-validation/>`_ directory. Its tagged
version, installation package, source archive and retained evaluation records
are described there.

* `Codec SIMD Validation <codec-simd-validation/>`_: an installable toolkit
  and historical case benchmark covering arithmetic, predictor state and
  local dispatch in x265, SVT-AV1 and AOM.
* `OpenH264 AArch64 SAD <cases/openh264-aarch64-sad/>`_: records for the
  block-matching optimization.

Each directory identifies its source revisions, evaluation scope and
applicable license terms.

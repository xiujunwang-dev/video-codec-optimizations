根因和影响：calc_energy_4x4() 使用 vaddvq_u16 将八个通道归约到
16 位结果；12-bit 输入的 SATD 可超过 65535。把变量声明为 int
不能挽回在指令内部已经丢失的高位。修复使用 vaddlvq_u16 进行
32 位归约，覆盖 Neon 与采用同样求和方式的 SVE2 路径。

最小输入，参考重建块全零，像素步长均为 4：
4095    0 4095    0
   0    0    0    0
   0    0 4095 4095
   0 4095 4095    0

SATD=73710，DC 项=24570>>2=6142，C 与独立计算结果为 67568。
旧 Neon 在求和时得到 8174，最终错误结果为 2032。
修复后返回 67568。原问题影响 psy-rd 的率失真决策，可能改变
模式选择、残差编码、码率和重建图像，不限于色度 SAO 或 CTU16。
同一输入关闭 psy-rd 后，原 12-bit/CTU16/I420 对照恢复一致。
未对真实片源的画质或 BD-rate 损失做定量评估。
